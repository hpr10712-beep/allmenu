⚠️ Firebase Rules menolak akses
Panel ini berjalan tanpa Firebase Auth, jadi butuh rules yang mengizinkan baca/tulis.
Buka Firebase Console → Realtime Database → Rules, ganti dengan:
{ "rules": { "adminConfig": { ".read": true, ".write": true }, ".read": true, ".write": "auth != null" } } Lalu klik Publish dan refresh halaman ini.

Banner Teks (Home)

Banner informasi berikon yang muncul di atas kartu profil pengguna.

Banner Foto (Slideshow)

Slideshow foto yang muncul di menu Home, di atas Papan Peringkat.

Jika lebih dari 1 foto, slideshow otomatis berjalan + tombol navigasi muncul. Jika hanya 1 foto, tampil statis tanpa slide. Rekomendasi ukuran: 1200×525 px.
Belum ada foto. Klik "Tambah Foto" untuk mulai.

Quick Menu Home

Tombol shortcut yang muncul di grid bawah hero card di menu Home.

Isi URL Gambar untuk tampilan gambar, atau kosongkan untuk pakai ikon SVG bawaan.

Menu Play

Daftar mode/game yang muncul di halaman Play. Bisa ditambah game apapun.

Action menentukan apa yang terjadi saat item diklik. Untuk game eksternal, pilih Buka URL dan isi kolom URL.

HTML Tambahan (Menu Play)

Kode HTML mentah yang akan disisipkan di akhir daftar menu Play.

Gunakan class .play-card untuk styling otomatis. Atribut yang didukung: data-admin-action="url" + data-admin-url="..."
